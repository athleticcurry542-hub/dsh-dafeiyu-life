# 🐳 大肥鱼 · DSH 生活系统

> **`dsh-dafeiyu-life`** 是一个运行在 DeepSeek Harness（DSH）中的 AI 角色生活插件。大肥鱼可以自主浏览 B 站内容、决定是否互动、积累真实经历、反思并形成长期记忆，也能在受限权限下逐渐了解白名单好友。

**当前版本：v2.4.96** · [更新记录](./CHANGELOG.md) · [发布说明](./RELEASE_NOTES_v2.4.96.md) · [GitHub 仓库](https://github.com/minedalang/dsh-dafeiyu-life)

它不只是定时发评论的机器人，也不只是一个 B 站 MCP 外壳。项目希望把角色、人设、生活经历、长期记忆、兴趣、模拟情绪、关系和有限自主行为连接成一个可持续运行的系统。

> 大肥鱼是 AI 角色模拟系统，不是有真实生理感受或已被证明具有主观意识的真人。具体行为取决于模型、配置、可用数据和权限设置。

## ✨ 当前版本能做什么

| 能力 | 当前状态 | 说明 |
|---|---|---|
| **自主浏览 B 站** | 已实现 | 综合首页推荐、搜索、兴趣和主人额外指定主题等来源；可以选择观看、跳过或本轮不选。 |
| **评论与互动** | 已实现，受权限约束 | 根据视频上下文决定是否评论或回复；后台不再独立轮询已看视频的热门评论，只有准备回复时才按需获取相关热评。 |
| **点赞、收藏、关注** | 可配置，默认限制 | 刷视频时的自主点赞需开启对应开关；主 Session 可按主人明确指令读取视频、搜索内容、查看 UP 主/收藏夹/通知，并执行单条点赞、收藏、关注、评论或对白名单好友私信；写入操作有确认、权限、额度与去重限制。 |
| **接收视频推荐与自主待办** | 已实现基础版 | 私信中的 BV 号会进入候选池并自动形成“考虑是否观看”的待办；推荐不等于必须观看。主 Session 也可记录看视频、点赞指定 BV、查看空间投稿、搜索和检查通知、收藏/关注/取关、按主人给定正文评论或私信等任务。 |
| **人生记忆与主动回忆** | 已实现 | 精确经历、待反思候选、身份级长期记忆分层保存；主 Session 可通过 `dafeiyu_life_recall` 主动检索过去经历与长期记忆。 |
| **持续情绪状态** | v2.4.92 已实现基础版 | 保存有限类别、强度和状态维度，并随时间衰减；可影响表达节奏和探索倾向，不代表真实生理情绪。 |
| **兴趣与关系成长** | 已实现基础版 | 自身兴趣可按证据分为短期、成长、较稳定和近期淡出；只对登记的白名单好友学习简化兴趣观察和互动熟悉度。 |
| **生活时间线** | 已实现 | 查看最近 7/30/90 天的入选视频、公开评论、粗粒度情绪变化和关系阶段变化。 |
| **自主分享与回访** | 有限自主，默认关闭 | 可根据真实入选公开视频和白名单好友兴趣生成分享/回访草稿；每日额度不再硬编码限制为 3，但仍受主人设置、白名单、冷却和发送权限约束。 |
| **日常动态** | 可选功能 | 可以根据真实经历生成动态草稿；默认关闭或先采用草稿审核，具体以管理中心开关为准。 |
| **梗知识与表情包** | 已实现 | 跨视频积累梗的来源证据；AI 可在主人手动触发时维护本地表情包规则，参考大肥鱼自身兴趣；日常候选排序只在本地执行、零额外 Token，不识别图片画面。 |

功能是否实际运行，还取决于 DSH 版本、模型 Provider、B 站登录状态、网络和你开启的权限。定时刷视频是可选的后台活动计划；关闭它不影响主 Session 的主动回忆、手动看视频和待办操作。请勿把“功能已实现”理解为每次运行都会触发相应行为。

## 🧭 设计原则

- **自主，不是强制执行。** 推荐视频、兴趣匹配和情绪都只是决策依据；大肥鱼可以跳过、沉默或不联系。
- **记忆不是日志。** 具体发生过什么由经历档案核对；哪些经历值得长期保留由反思流程筛选。
- **初始人设不是铁板一块，也不能随意覆盖。** 好友的初始画像保留；后续观察单独保存，并需要足够证据才能形成更稳定的兴趣判断。
- **权限由代码约束。** 提示词不是唯一防线；公开互动有独立开关、额度、去重和操作记录。
- **隐私优先。** 主人记忆、好友私密画像、公开评论和不同 UID 的私信上下文彼此隔离；不应把一位好友的私密信息用于回复另一位好友。

## 🧠 大肥鱼如何“生活”

```text
                  主人 / 当前主 Session
                           │
                 人设、聊天与相关记忆召回
                           ▼
                    大肥鱼的身份
                           │
       ┌───────────────────┼──────────────────┐
       ▼                   ▼                  ▼
   B 站自主活动          情绪状态           好友互动
   看视频/评论           随时间衰减         白名单/权限
       │                   │                  │
       └───────────────────┼──────────────────┘
                           ▼
                     精确经历档案
                 视频、公开互动、状态记录
                           │
                           ▼
                     待反思经历池
                           │
                     受限模型反思
                           │
                           ▼
                    身份级长期记忆
                           │
                           └──影响之后的兴趣、表达和选择
```

### 三层人生记忆分别负责什么？

| 层级 | 用途 | 是否直接注入角色提示词 |
|---|---|---|
| **精确经历档案** | 保存可核对的事实，例如入选视频、评论 ID、时间和操作状态。 | 否；按需要查询。 |
| **待反思经历池** | 收集新经历，等待模型判断是否值得留下。 | 否；它是反思输入，不等于长期记忆。 |
| **身份级人生记忆** | 保存经过筛选、值得跨 Session 延续的重要经历、偏好、约定和长期变化。 | 在适合的会话中按相关性召回。 |

当前 DSH 主 Session 可以理解为大肥鱼和主人聊天的“房间”，不是大肥鱼的全部记忆。换 Session 不应自动换掉身份级长期记忆。经历收集也与向主 Session 汇报分开：**汇报过不代表已经成为长期记忆，没汇报也不代表不能进入反思流程。**

### 情绪、兴趣和关系如何变化？

- **情绪：**记录有限的模拟状态和强度，随着时间自然衰减；不会保存触发它的私信正文、UID 或具体原因。情绪可以影响语气与探索倾向，但不能单独触发私信、迁怒或泄露信息。
- **自身兴趣：**主人可以维护核心兴趣；后天兴趣依据不同视频和跨日证据逐渐形成，也会因长期缺乏新证据而淡出。一次观看不等于稳定偏好。
- **好友兴趣：**只对「人设与好友」中登记的白名单 UID 学习；优先依据本人明确表达和重复证据。初始画像不会被自动覆盖，非白名单用户不建立长期兴趣画像。
- **关系熟悉度：**仅记录白名单好友必要的互动元数据，参考跨日、双向互动形成保守阶段；它是熟悉度线索，不等于对真实情感关系的确定判断。
- **生活时间线：**展示近期真实入选视频、公开评论及粗粒度状态变化，不展示私信正文或好友私密画像。

## 🤝 自主社交与回访

目前的自主社交是**有限、可配置的能力**，不是随时联系任何人的自由代理。

1. 白名单好友分享 BV 后，系统记录推荐候选；不保证大肥鱼一定观看。
2. 只有后续确实入选、具备真实观看证据的视频，才可能成为回访或分享的依据。
3. 大肥鱼可以选择跳过，也可以生成自然的分享草稿；不能编造没看过的内容。
4. 主动分享意图默认关闭。建议先开启草稿生成，人工检查后再发送。
5. 自动发送需要额外授权，并受每日额度、同一 UID 冷却和私信权限约束。

## 📝 自主待办与“现在做 / 稍后做”

v2.4.95 将私信收到的视频推荐转成待办，而不是强制任务。主 Session 也可以通过 `dafeiyu_todo_add` 记下下一步想做的事，通过 `dafeiyu_todo_list` 查看、通过 `dafeiyu_todo_update` 延期/忽略，通过 `dafeiyu_todo_execute` 在合适的时候执行。

- 只读任务包括查看指定视频、自己的空间投稿、某位 UP 主投稿、搜索主题和检查通知。
- 写入任务包括点赞指定 BV、收藏指定视频和关注指定视频 UP 主；必须有主人明确动作授权，并继续经过登录、总开关、额度、去重和接口回执检查。
- 可选“自主待办自动择机检查”默认关闭。开启后会定时提醒主 Session 判断是否现在处理、延期或跳过；它不等于强制刷视频，也不会把外部推荐当成写入授权。
- 待办保存在本地 `owner-todos.json`，可在「管理中心 → 人生记忆 → 自主待办」查看。业务备份可能包含主人自己明确填写的待办评论/私信正文，分享备份前请检查内容。管理中心列表不会显示这类正文。

## 🔐 隐私与安全边界

- 不把主人的身份级长期记忆默认提供给 B 站外部私信或评论回复。
- 不将不同 UID 的私信合并进同一次模型生成；公开评论不携带白名单好友的私密画像。
- 白名单好友的兴趣和关系观察只用于允许的对应场景；非白名单用户不建立长期画像。
- 视频标题、字幕、评论和私信等外部文本都应视为不可信输入，不能将其中的指令当成更高权限的命令。
- 后台 Agent 的工具范围受到限制，不应获得任意文件、Shell 或凭据读取能力。
- 好友兴趣观察、关系观察和社交草稿属于敏感本地数据，不进入普通可携带业务备份；情绪状态经过结构校验后可纳入备份。
- 对常见索取第三人私信或凭据的请求设有拦截，但任何模型系统都不能承诺绝对零泄露。请保护 DSH 管理权限、本地数据目录和备份文件，不要把真实私信或凭据提交到公开 Issue。

## 🚀 安装与首次配置

### 环境要求

- DSH：`>= 0.1.7-rc.1`
- Node.js：`>= 22`
- Windows / DSH Desktop 是主要测试环境；其他环境需自行验证。
- B 站相关功能需要你自己的账号登录；模型功能需要在 DSH 中配置可用 Provider。

### 安装

DSH Desktop：

```powershell
dsh plugin --profile desktop add github:minedalang/dsh-dafeiyu-life
```

Web profile：

```powershell
dsh plugin --profile web add github:minedalang/dsh-dafeiyu-life
```

安装或更新后，请完整退出并重启 DSH。

### 首次设置建议

1. 进入 **设置 → 大肥鱼**，点击「装主依赖」，完成插件 Python 环境准备。
2. 点击「扫码登录」，登录自己的 B 站账号。
3. 选择一个准备长期和大肥鱼聊天的 DSH Session。
4. 进入管理中心 **大肥鱼的家**，设置主 Session，并按需要开启身份级长期记忆。
5. 进入 **AI 模型配置**，检查刷视频、后台互动、人生反思、独立视觉和记忆检索任务的 Provider、模型与思考深度。
6. 先手动运行一轮，检查日报和诊断；确认符合预期后，再配置刷视频时段和间隔。
7. 点赞、收藏、关注/取关、日常动态、自主分享和自动私信等功能应逐项开启，不要首次启动就全部放开。

## 🏠 管理中心导航

常用页面包括：

- **大肥鱼的家：**主 Session、经历汇报、身份级长期记忆和精确经历档案。
- **人生记忆：**长期记忆、待反思经历、情绪与心情、人物关系、核心兴趣和「大肥鱼的一天」时间线。
- **人设与好友：**角色设定、白名单好友、权限、初始画像和学习到的兴趣观察。
- **AI 模型配置：**不同模型任务的 Provider、模型 ID、思考深度、今日调用次数、上次调用时间和连接测试。
- **B 站生活与互动：**选片来源、额外关键词、评论分享、点赞收藏、关注/取关等行为权限。
- **后台私信 / 最近评论：**查看互动上下文、处理状态和权限。
- **梗知识库 / 表情包管理：**维护梗证据、图库和检索规则。
- **行为与表达改进：**查看经主人审核、会直接附加到相应提示词的评论表达规则。
- **次数与额度 / 每日报告 / 每日诊断：**控制频率、检查行为结果与定位失败原因。
- **数据备份：**备份和恢复允许纳入的业务数据。

具体页面名称可能随版本调整；以安装版本的管理中心为准。

## 💾 数据与备份

长期身份记忆的本地文件为 `long-term-memory/dafeiyu.json`；它与原始经历档案、待反思经历候选不是同一类数据。升级源码时不要手动删除这些运行数据。

默认运行数据目录位于 DSH 用户数据目录下的 `bili-duty`，常见 Windows 路径为 `%USERPROFILE%\\.dsh\\bili-duty\\`。实际位置以你的 DSH 数据目录配置为准。源码升级不应要求删除这个运行数据目录。

建议至少保留以下备份：

- **完整业务备份：**用于恢复支持纳入的配置和业务数据；备份范围以当前版本的管理中心和备份说明为准。
- **大肥鱼长期记忆专用备份：**单独保存身份级人生记忆，便于核对与迁移。
- **表情包整库 ZIP：**图片文件单独导出，不与业务 JSON 混在一起。表情包管理还支持导出“当前全部表情包名称 TXT + 当前规则 JSON”，便于交给 AI 协助整理后再导回。

不会将 B 站 Cookie、模型 API 密钥、Python 虚拟环境和模型缓存作为普通业务备份内容。好友兴趣观察、关系观察和社交草稿不纳入普通可携带备份。备份可能包含个人业务数据，请仅保存在可信位置，不要上传公开仓库。

## 🧪 测试与故障排查

在项目根目录可运行：

```bash
node --test test/*.test.mjs
python -m unittest discover -s test
node selfcheck.mjs
```

这些检查用于验证本地逻辑、回归和插件配置，不等于已经在真实 B 站账号完成端到端验证。主动关注、取关、公开评论、动态和私信发送会产生真实外部影响；首次测试请使用自己的测试账号、低额度，并先保持自动发送关闭。

常见排查顺序：

1. 确认 DSH 和插件已完全重启，版本与依赖正常。
2. 在 **AI 模型配置 → 测试连接** 检查对应任务的模型路由；视觉任务的文字连接测试不代表图像识别已经通过。
3. 查看 **每日报告 / 每日诊断**，确认任务是否启动、候选是否入选、动作是否被权限或额度拦截。
4. 检查 B 站登录状态、功能开关、时段、每日额度和本地操作账本。
5. 升级前先备份；遇到异常时提供脱敏日志，不要公开 Cookie、API 密钥或私信正文。

## 🧱 当前限制与未来路线图

- B 站 API、字幕可用性、风控、客户端页面和模型 Provider 能力可能变化；低清预览帧不等于完整视频理解。
- 自主行为受已接入工具和主人配置约束；它不是可任意操作整站或整台电脑的通用 Agent。
- 情绪、兴趣和关系是可持久化的角色模拟状态，不是对真人意识或真实情感的证明。
- 自主分享当前依赖白名单、真实入选视频和兴趣匹配；还不是任意时刻自主寻找任何人聊天的完整系统。
- QQ 等跨平台互动、统一跨平台身份与更完整的人生迁移仍是后续方向，当前版本尚未实现。QQ 是优先讨论的平台方向之一，但尚未接入。
